Overview
--------

RedOPS is organized into several main packages:

* **redops.core**: Core functionality including context, configuration, and models
* **redops.modules**: Security assessment modules (recon, analysis, intel, reporting)
* **redops.pipelines**: Pipeline loading, validation, and execution
* **redops.web**: Web dashboard and REST API
* **redops.mcp**: Model Context Protocol server for AI integration
* **redops.cli**: Command-line interface
